# 00｜范围基线与设计决策

版本 1.0.0。本文定义首版，不是行业商业化或医疗合规认证承诺。

## 1. 假设与明确选择
| 项目 | V1冻结选择 |
|---|---|
| 使用者 | 研发情报分析员、研究报告审核员、小团队管理员 |
| 数据范围 | 公开研究资料；禁止病历、患者身份数据和患者匹配 |
| 来源地区 | ClinicalTrials.gov 与 PubMed 所覆盖资料；不宣称中国或全球试验全集 |
| 语言 | 界面中文；保留来源英文；中译文单独标明机器辅助翻译 |
| 功能规模 | 1个部署支持多个隔离workspace；先验证2个workspace隔离 |
| 研究产物 | 结构化研究报告、Markdown/JSON导出；V1不要求PDF/Word导出 |
| 报告审核 | 人工批准后发布，发起人与批准人不能相同；不自动发布模型结论 |
| 订阅 | 每日/每周固定时刻，IANA时区；站内+开发SMTP；真实发信显式启用 |
| 演示 | 全虚构药物 PX-101、PX-202；外部标识以 DEMO 开头，不向官方查询 |
| 首版搜索 | 标识/别名精确检索+结构化筛选+Postgres文本查询；向量召回后置 |
| 通用Agent能力 | 禁止任意命令/下载执行/任意链接抓取；仅经过授权的领域工具 |

## 2. 范围分级
### V1 MUST
账户与会话、workspace角色；药物档案和有来源的别名；trial/publication适配；不可变快照与重复观察记录；字段差异与事件版本；基于证据缺口的真实模型工具循环；任务取消/失败/恢复；结论证据绑定；审核和发布；订阅、投递、审计；现代前端；离线与联网验收。

### V1.1 / SHOULD，不得伪装已完成
openFDA标签与召回；经审核的ToolUniverse工具；向量/混合检索；有版权依据的全文摄入；多源自动实体对齐；更复杂研究子任务；PDF导出；外部SSO；对象存储。

### 不做
患者诊疗/试验入组自动决策、个性化用药、药物疗效排行、药物设计与合成、全网爬虫、社交推荐、支付会员、多租户商业计费、Kubernetes/GPU平台、自动论文写作投稿。

## 3. 完成门槛
- 离线：完整用户旅程和安全/版本/重试场景通过，可重置复演。
- 联网：固定上游SHA；真实模型完成至少3种分支任务；两个真实适配器均有实际响应和字段映射测试记录。
- 不满足联网门槛时只标 `DEMO_READY`，不能标 `V1_RELEASE_READY`。
- 使用真实资料进行小规模联网验收不等于临床有效性或生产可靠性验证。

## 4. 产品必须展示的限制
页脚：“本平台用于公开研发信息研究，不用于诊断、治疗或用药决策。”
资料不全：“本次仅覆盖已成功访问的来源；未检索到不代表不存在。”
研究状态和来源覆盖分别展示；任务完成不表示来源完整，更不表示医学结论成立。

## 5. 文档基线不能代替真实上游锁
`delivery/upstream.lock.json` 的 SHA 初始为 null。实现者必须填实际完整SHA、依赖锁、SDK探针记录。当前已查阅官方文档但未获得可验证的提交SHA，不编造一个看似真实的值。
